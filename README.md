# Portfolio

A responsive portfolio website showcasing my skills, projects, and experience as a junior front-end developer based in Kielce, Poland.

**Live site:** [kubazap.github.io](https://kubazap.github.io/)

## Project Structure

```text
kubazap.github.io/
├── index.html              # Main portfolio page
└── assets/
    ├── css/                # Stylesheets and font definitions
    ├── js/                 # Application logic and interactions
    ├── img/                # Photos, logos, and project images
    ├── fonts/              # Self-hosted fonts
    └── vendor/             # Third-party libraries
```

## Features

- **Responsive layout** adapted to mobile and desktop screens.
- **Mobile navigation** with an animated slide-in menu.
- **Scroll spy** highlighting the currently active section.
- **Animated timeline** with scroll-based progress.
- **Interactive project slider** powered by Swiper.
- **Scroll-triggered animations** using AOS.
- **Image optimization** with WebP, `srcset`, and lazy loading.

## Technologies

- **HTML5, CSS3**: Page structure, responsive layouts, and animations.
- **JavaScript (ES6)**: Interactive elements and dynamic behavior.
- **Bootstrap 5.3**: Grid system and UI components.
- **Bootstrap Icons**: Interface icons.
- **Swiper**: Project carousel.
- **AOS**: Scroll-triggered animations.
- **GitHub Pages**: Hosting and deployment.

## Deployment

The website is hosted on GitHub Pages and deployed automatically from the root of the `main` branch.
